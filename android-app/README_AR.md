# تطبيق كاشير المحل للأندرويد

هذه نسخة اختبار Android من برنامج الكاشير الحالي. تحتفظ بواجهة البيع وإدارة المنتجات والكتالوج المحلي، وتستبدل ماسح المتصفح بماسح كاميرا أصلي.

## المكونات

- واجهة البرنامج الحالية تعمل داخل WebView محلي باستخدام WebViewAssetLoader، ولذلك لا تحتاج اتصال إنترنت لفتح الواجهة.
- التخزين يستخدم IndexedDB داخل أصل التطبيق المحلي.
- المسح يستخدم CameraX + ML Kit Barcode Scanning مع نموذج مضمّن داخل التطبيق.
- يدعم EAN-13 وEAN-8 وUPC-A/UPC-E وCode 128 وCode 39 وCode 93 وCodabar وITF وQR.
- تحليل الصور يستخدم STRATEGY_KEEP_ONLY_LATEST حتى لا تتراكم الإطارات إذا كان التحليل مشغولًا.
- يدعم اقتراح التكبير التلقائي عند اكتشاف باركود بعيد، وفلاش الكاميرا عند توفره.
- صوت نجاح المسح صادر من Android ToneGenerator.

## الحصول على APK

البناء يتم تلقائيًا بواسطة GitHub Actions عند تحديث ملفات المشروع.

1. افتح المستودع الخاص bokar6221/supermarket-pos.
2. افتح تبويب Actions.
3. اختر workflow باسم Build Android POS APK.
4. افتح أحدث تشغيل بحالة نجاح.
5. من قسم Artifacts نزّل supermarket-pos-android-debug.
6. فك ضغط الملف على الكمبيوتر، وانقل app-debug.apk إلى Samsung A13.
7. افتح APK وثبّت التطبيق. قد يطلب Android السماح بالتثبيت من هذا المصدر.

لا يحتاج المستخدم إلى Android Studio لبناء النسخة التجريبية؛ GitHub Actions يبني APK في بيئة سحابية.

## نقل البيانات من نسخة المتصفح

بيانات Chrome/المتصفح وبيانات APK منفصلة لأن لكل منهما مساحة IndexedDB مختلفة.

1. افتح نسخة المتصفح القديمة.
2. ادخل إلى النسخ الاحتياطي واضغط تنزيل نسخة احتياطية.
3. انقل ملف JSON إلى الهاتف.
4. افتح تطبيق Android، ثم النسخ الاحتياطي ثم استعادة نسخة.
5. اختر ملف JSON وانتظر رسالة نجاح الاستعادة.

عند تصدير النسخة من APK، سيطلب Android اختيار مكان حفظ ملف JSON.

## ملاحظات الاختبار

- هذه نسخة اختبار Debug وليست إصدارًا نهائيًا موقّعًا للنشر التجاري.
- لم يتم اختبارها فعليًا على Samsung A13 حتى الآن؛ يجب اختبار صلاحية الكاميرا وسرعة المسح والصوت على الجهاز نفسه.
- بيانات التطبيق محلية على الهاتف ولا تتزامن تلقائيًا مع نسخة المتصفح أو أجهزة أخرى.
- إذا لم تمنح إذن الكاميرا، فلن يعمل زر المسح.
