# برنامج كاشير السوبر ماركت

تطبيق ويب تقدمي عربي (PWA) للمحلات الصغيرة، مصمم للعمل محلياً على هاتف Android واحد في الإصدار الحالي.

## ما يعمل في النسخة الحالية
- واجهة عربية RTL مناسبة للموبايل.
- كتالوج منتجات: إضافة وتعديل وحذف، اسم وتصنيف وباركود اختياري ووحدة وسعر وتكلفة اختيارية.
- أصناف سريعة للاختيار من شاشة الكاشير، بما فيها المنتجات السائبة دون باركود.
- بيع بالقطعة أو بالكيلو أو بالجرام، وبند يدوي لا يرتبط بالمخزون.
- مسح بالكاميرا عبر BarcodeDetector عندما يدعمه المتصفح، مع إدخال الباركود يدوياً كبديل.
- سلة مبيعات وخصم على الفاتورة وطرق دفع: نقدي وإلكتروني وآجل.
- حفظ الفواتير محلياً وسجل للفواتير وتفاصيلها.
- متابعة مخزون اختيارية للمنتجات المسجلة، وخصم الكمية عند حفظ الفاتورة.
- تصدير واستعادة نسخة JSON محلية.
- قاعدة IndexedDB وواجهة PWA قابلة للتخزين للعمل دون اتصال بعد التحميل الأول.

## التشغيل
يجب تشغيل التطبيق عبر localhost أو HTTPS لتثبيت PWA واستخدام الكاميرا. افتح رابط التطبيق من متصفح Android حديث، ثم اختر إضافة إلى الشاشة الرئيسية. قد تختلف إمكانية مسح الباركود حسب دعم المتصفح للـ BarcodeDetector والكاميرا.

## تحذيرات وحدود مهمة
هذه نسخة تطوير أولية وليست إصداراً تجارياً معتمداً أو برنامج فواتير ضريبية. لم يتم اختبارها بعد على هاتف Android فعلي أو طابعة حرارية.
- لا يوجد حتى الآن نظام مستخدمين وصلاحيات أو سجل تدقيق.
- لا توجد مشتريات أو موردون أو مرتجعات أو جرد أو خزينة ومصروفات.
- تقارير الأرباح غير متاحة؛ تسجيل تكلفة المنتج وحده لا يكفي لإظهار ربح موثوق مع المرتجعات وحركات المخزون.
- لا توجد مزامنة بين عدة أجهزة أو فروع.
- النسخ الاحتياطي JSON غير مشفر؛ احفظه في مكان آمن ولا تشاركه.
- الاستعادة تستبدل البيانات الحالية بالكامل.
- لا تستخدم التطبيق لحسابات محل حقيقية قبل إكمال اختبارات القبول والنسخ الاحتياطي والاستعادة.

## بنية الملفات
- `index.html`: واجهات الكاشير والمنتجات والفواتير والنسخ الاحتياطي.
- `styles.css`: التصميم.
- `app.js`: منطق الواجهات والتشغيل.
- `db.js`: IndexedDB والمعاملات المحلية.
- `manifest.json` و`sw.js`: إعدادات PWA والعمل دون اتصال.
- `docs/`: المتطلبات والقرارات وخطة الاختبار والإصدار.

GitHub لحفظ الكود فقط، ولا تضع بيانات المحل أو ملفات النسخ الاحتياطي في المستودع.
