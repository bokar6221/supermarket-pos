# نظام كاشير وإدارة محل — Android أولًا

تطبيق كاشير عربي RTL للمحلات الصغيرة والمتوسطة، بواجهة مصممة للموبايل وماسح باركود Android أصلي باستخدام CameraX وGoogle ML Kit.

## الوظائف الموجودة في فرع التطوير

### البيع والكاشير
- بيع وفواتير وسلة وخصومات وطرق دفع نقدي/إلكتروني/آجل.
- تبويبان داخل الكاشير: مسح الباركود والبيع اليدوي؛ نموذج البيع اليدوي يظهر داخل مساحته المخصصة فقط.
- إدارة المنتجات والباركود والتصنيفات ووحدات القطعة والكيلو والجرام.
- ماسح Android أصلي عبر CameraX + ML Kit، مع فلاش وتركيز تلقائي وقراءة صيغ باركود متعددة.
- حفظ محلي باستخدام IndexedDB داخل Android WebView.

### المنتجات
- تبويبان مستقلان لإضافة المنتج وقائمة المنتجات.
- تصفية قائمة المنتجات حسب التصنيف، مع البحث بالاسم والباركود.
- تعديل المنتج والعودة تلقائيًا إلى شاشة القائمة بعد الحفظ.

### المخزون والجرد
- تبويبات مستقلة لتنبيهات المخزون، وتسوية الحركة، والجرد الفعلي، وأرصدة الأصناف، وحركة المخزون.
- حد إعادة طلب وتنبيهات النواقص والنفاد وقيمة المخزون بالتكلفة.
- حركات للبيع والشراء والرصيد الافتتاحي والتسويات والجرد.
- جرد فعلي مع عرض الفروق واعتمادها في سجل الحركة.

### المشتريات والموردون
- تبويبات مستقلة لإضافة مورد، وفاتورة مشتريات، وسداد حساب مورد، وسجل المشتريات.
- عرض الموردين وأرصدتهم وكشف حساباتهم داخل تبويب السداد.
- تحديث المخزون تلقائيًا عند شراء البضاعة وتحديث التكلفة بمتوسط التكلفة المرجح.

### تحسينات الهاتف
- تبويبات داخلية قابلة للتمرير أفقيًا بدل عرض جميع الأقسام الطويلة في صفحة واحدة.
- ضبط عرض الشاشة ومنع تجاوز المحتوى إطار الموبايل؛ الجداول العريضة تحتفظ بتمرير أفقي داخل منطقتها.

## قاعدة البيانات والعمل دون إنترنت

- قاعدة البيانات IndexedDB إصدار 3.
- ترحيل قاعدة البيانات يضيف مخازن الموردين والمشتريات والمدفوعات والجرد دون حذف المنتجات والفواتير القديمة.
- كل جهاز يحتفظ بقاعدة محلية مستقلة في الوضع الحالي.
- لا توجد بعد مزامنة Online أو Offline بين الأجهزة؛ النسخ الاحتياطي ليس مزامنة.
- يلزم الاحتفاظ بنسخ احتياطية خارج الهاتف واختبار الاستعادة قبل الاستخدام التجاري.

## حدود النسخة الحالية

هذا فرع تطوير واختبار، وليس إصدارًا تجاريًا تم اعتماده ميدانيًا. لم يتم بعد تنفيذ العملاء والمديونيات والتحصيل، المرتجعات، الخزينة والورديات والمصروفات وصلاحيات الموظفين. لم يتم بعد تنفيذ مزامنة عدة أجهزة أو حسابات الاشتراك. وحدة الصيدلية والذهب غير مكتملة.

الطباعة مؤجلة للمرحلة الأخيرة كما هو مخطط. التطبيق ليس نظام إيصال ضريبي/فاتورة إلكترونية معتمدة حتى استكمال التكامل والمتطلبات الرسمية.

## سلامة البيانات

- لا تضع نسخًا احتياطية حقيقية للمحل داخل GitHub.
- عند الاستعادة يتم استبدال بيانات الجهاز الحالية ببيانات ملف النسخة.
- لا تحذف منتجًا له رصيد مخزون؛ سجل التسوية أولًا.
- يفضل إيقاف البيع مؤقتًا أثناء الجرد الفعلي لتجنب اختلاف الكمية بسبب عمليات بيع متزامنة.
- متوسط التكلفة يُحسب عند إدخال مشتريات جديدة من الرصيد والتكلفة السابقين؛ راجع تكلفة الأصناف القديمة قبل الاعتماد المحاسبي.
