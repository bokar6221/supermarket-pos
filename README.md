# برنامج كاشير السوبر ماركت

نسخة أولية عربية تعمل على Android عبر متصفح حديث كتطبيق ويب تقدمي (PWA)، مع تخزين محلي على الجهاز باستخدام IndexedDB.

## الحالة الحالية
هذه بداية المشروع (Scaffold)، وليست نسخة جاهزة للاستخدام التجاري أو لحفظ حسابات محل حقيقية.

### ما يتضمنه الهيكل الأولي
- واجهة عربية RTL مناسبة للموبايل.
- هيكل تطبيق PWA قابل للتثبيت.
- طبقة تخزين محلية IndexedDB.
- ملفات توثيق المتطلبات وخطة التنفيذ.

## التشغيل محلياً
يمكن فتح `index.html` مباشرة للمعاينة الأساسية، لكن ميزات PWA والكاميرا تحتاج إلى تشغيل الموقع عبر localhost أو HTTPS. لا توجد حاجة إلى خدمة مدفوعة.

## تنبيه مهم
لا تستخدم هذه النسخة في البيع الفعلي قبل استكمال واختبار النسخ الاحتياطي والاستعادة، الفواتير، الصلاحيات، ومسح الباركود على أجهزة حقيقية.

## بنية المشروع
- `index.html`: واجهة التطبيق.
- `styles.css`: التصميم.
- `app.js`: منطق الواجهة.
- `db.js`: قاعدة البيانات المحلية.
- `manifest.json` و `sw.js`: إعدادات PWA والعمل دون اتصال.
- `docs/`: المتطلبات والقرارات الفنية.
