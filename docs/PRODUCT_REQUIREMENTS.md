# متطلبات النسخة الأولية

## الهدف
تجربة برنامج كاشير ومبيعات لمحل سوبر ماركت صغير، يعمل على هاتف Android واحد لكل محل، دون اشتراك أو خدمة سحابية مدفوعة للوظائف الأساسية.

## قرارات معتمدة
- جهاز واحد في الإصدار التجريبي الأول.
- البيانات تحفظ محلياً على الهاتف.
- واجهة عربية RTL ومناسبة لشاشة الهاتف.
- العمل دون إنترنت بعد تحميل التطبيق وملفاته.
- تصميم قاعدة البيانات يسمح بإضافة تعدد الأجهزة لاحقاً.
- GitHub مستودع الكود والتوثيق فقط، وليس قاعدة بيانات المحل.

## وظائف النسخة الأولى
1. إضافة المنتجات وتعديلها وحذفها.
2. دعم المنتجات ذات الباركود.
3. دعم أصناف بلا باركود مثل الجبن السائب واللانشون والبسطرمة.
4. البيع بالقطعة أو الوزن.
5. إدخال سعر مباشر يدوي لبند غير مسجل، مع توضيح أنه بند يدوي لا يخصم من مخزون صنف مسجل.
6. سلة مشتريات وحساب الإجمالي.
7. حفظ الفاتورة محلياً وعرض سجل الفواتير.
8. نسخ احتياطي وتصدير البيانات واستعادتها قبل الاعتماد الفعلي.

## خارج نطاق الإصدار الأول
- تعدد الهواتف والمزامنة.
- الطباعة الحرارية.
- المحاسبة المتقدمة والفروع.
- التكامل مع ميزان إلكتروني.

## قواعد مهمة
- حفظ اسم الصنف والوحدة والكمية وسعر الوحدة والإجمالي داخل بند الفاتورة وقت البيع، حتى لا تتغير الفواتير القديمة عند تعديل بطاقة المنتج.
- لا يسمح بحذف فاتورة معتمدة بصمت؛ يلزم مسار إلغاء واضح وسجل تدقيق في مرحلة الصلاحيات.
- لا نعرض أرباحاً دقيقة قبل تسجيل تكلفة شراء صحيحة وحركات المخزون.
- لا نستخدم بيانات عملاء حقيقية أو أسرار وصول داخل المستودع.
