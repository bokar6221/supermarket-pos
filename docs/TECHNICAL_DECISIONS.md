# القرارات الفنية

## النسخة التجريبية
- Frontend: HTML + CSS + JavaScript بدون إطار ثقيل.
- Local database: IndexedDB.
- PWA: Web App Manifest + Service Worker.
- Barcode: سنختار مكتبة مفتوحة المصدر ونضمّن ملفاتها محلياً بعد اختبار دعم كاميرات أجهزة Android؛ لا نعتمد على CDN أثناء التشغيل دون إنترنت.
- GitHub: مستودع خاص للكود والتوثيق.

## لماذا IndexedDB؟
قاعدة بيانات مدمجة في المتصفح، مناسبة لتخزين سجلات المنتجات والفواتير محلياً. لكنها لا تغني عن النسخ الاحتياطي؛ حذف بيانات المتصفح أو فقد الهاتف قد يؤدي إلى فقد البيانات.

## التوسع لاحقاً
عند إضافة عدة أجهزة، نحتاج خادماً محلياً داخل المحل أو آلية مزامنة مدروسة، ومعرّفات فريدة للفواتير والأجهزة، ومعالجة تعارض المخزون. لا نفترض أن قواعد بيانات الهواتف ستتشارك البيانات تلقائياً.

## الأمان والخصوصية
- عدم تخزين كلمات مرور أو مفاتيح API أو بيانات حساسة في GitHub.
- بيانات كل محل تبقى على جهازه في هذه المرحلة.
- إضافة تصدير واستعادة مشفرين خيار مطلوب قبل الاستخدام التجاري، مع اختبار فعلي للاستعادة.
