# القرارات الفنية

## البنية الحالية
- HTML/CSS/JavaScript خفيف.
- PWA عبر Web App Manifest وService Worker.
- IndexedDB محلياً، schema version 2.
- مخازن البيانات: products, invoices, settings, movements.
- قارئ BarcodeDetector الأصلي عند دعمه، مع إمكانية إدخال الباركود يدوياً. لا يعتمد التطبيق على CDN.
- GitHub مستودع الكود والتوثيق فقط.

## سلامة البيانات
- حفظ الفاتورة وتحديث رصيد المنتجات المتتبعة يتمان داخل معاملة IndexedDB واحدة.
- إذا أصبح الرصيد سالباً تُلغى المعاملة ولا تحفظ الفاتورة.
- كل بند فاتورة يحتفظ ببيانات المنتج والسعر والوحدة وقت البيع.
- النسخ الاحتياطي JSON يشمل المنتجات والفواتير والحركات والإعدادات المتاحة حالياً.
- الاستعادة تستبدل محتويات قاعدة البيانات الحالية؛ يجب أخذ نسخة قبل الاستعادة.
- النسخة الاحتياطية الحالية غير مشفرة.

## التوسع
تعدد الأجهزة يتطلب خادماً محلياً أو مزامنة مع معرفات أجهزة وفواتير فريدة وآلية فض تعارض. لا يمكن ضمان رصيد موحد لحظياً بين أجهزة تعمل offline بصورة مستقلة.

## الأمان
- لا تخزن أسرار وصول أو بيانات محلات حقيقية في GitHub.
- إضافة مستخدمين وصلاحيات وسجل تدقيق مطلوبة قبل الاستخدام التجاري متعدد الموظفين.
- النموذج الحالي لا يقدم التزامات محاسبية أو ضريبية.
